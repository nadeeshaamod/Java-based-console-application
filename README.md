A Java console application for demonstrating common data structures, searching algorithms, graph traversal, and performance comparison.

## Features

- Array insertion, deletion, searching, and display
- Stack push, pop, peek, and display
- Circular queue enqueue, dequeue, peek, and display
- Linked list insertion, deletion, searching, and display
- Linear and binary searching
- Graph vertex and edge management
- Breadth-first search (BFS) and depth-first search (DFS) traversal
- Linear and binary search performance comparison
- Integrated main menu for accessing all components

## Requirements

- Java Development Kit (JDK) 8 or later

## How to Run

Compile all Java source files:

```bash
javac *.java
```

Run the application:

```bash
java Main
```

Use the displayed menu options to access each data structure and analysis feature.
